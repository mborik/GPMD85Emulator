- ZOFKA1   - Zofka the Turtle in BASIC (v1)

- ZOFKA2T  - Zofka the Turtle in BASIC with a print command (v2/v2A/v3)

             (on the PMD 85-3 it is necessary to switch to compatibility mode
              first by entering `JUMP FFF0` in the monitor).
